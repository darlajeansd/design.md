## 2024-05-18 - Prevent Code Execution via new Function() in compiler.ts
**Vulnerability:** MDX expressions were being evaluated directly using `new Function(..., "return " + expr)`. This allowed arbitrary code execution within the compiler's process for any user supplying MDX content.
**Learning:** Evaluated strings inside markdown/MDX must never be run through `new Function` or `eval()`. Doing so allows arbitrary execution outside the expected scope. Note that `node:vm` provides significantly better isolation than `new Function` as it avoids exposing the current global variables and the node environment directly to the execution context. When migrating `new Function('return ' + expr)` logic to `node:vm`, `vm.Script('(' + expr + ')')` with `runInNewContext({ ...scope })` must be used to avoid mutating the scope and allowing expressions with block-like syntax (like objects) to be interpreted correctly as expressions.
**Prevention:** Use `node:vm` context (`vm.runInNewContext`) to evaluate isolated scripts when basic context isolation is needed.
